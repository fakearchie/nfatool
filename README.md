Paste your token, pick an account, and you're in. archievable writes it straight into Steam's local cache and starts the client.

## Use it

1. **Import** — paste your code(s), one per line.
2. **Sign in** — switch to an account and launch Steam.
3. **Remove** — drop an account from the local cache.

Closes to the system tray — switch accounts from there too.
